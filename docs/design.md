# 日常 Health

用户已确认本地方案。目标是记录饮食、锻炼和身体变化；不提供医疗或热量目标建议。

2026-10-19 用户调整：顶部名称改为“我的健康记录”，删除两处页脚文案。增加用户自填的通用每日营养标准，在总览及饮食页的摄入区域显示比例、差额。标准存于顶层 targets，兼容无该字段的版本 1 记录和备份；不提供预设建议；零标准不除零；营养不全时只比较已知摄入并提示。

## 结构
- 饮食：早中晚及加餐，食物多选、临时添加、数量编辑、备注；食物库支持新建、编辑和删除。
- 锻炼：动作多选、临时动作、组数、每组数量（个/秒）、时长及感受；记录当日体重；动作库可维护。
- 总览：当天饮食和训练摘要、营养合计、体重和围度编辑、月份日历、近 7/30 天两张折线图。
- 公共：本地日期选择、前后一天、今天、备份导入导出、本地保存状态。

## 数据约定
营养字段为每基准份量的值，按实际数量/基准数量折算。空值保留未知。历史条目保存完整食物/动作快照，修改模板不改历史。体重及围度未填不视为零。时间窗口以所选日期为结束日期。历史趋势在无记录处断开。

localStorage 保存版本化 JSON，包括 foods、exercises、days。写入失败提示错误且不替换内存数据。导入先完整校验和展示记录量，确认后替换；保留导入前的本机恢复副本。导出包含全部个人记录，不提交到 GitHub。无跨设备自动同步。

## 视觉与验证
桌面左侧三项导航、右侧日志主栏；移动端顶部标题与底部导航。浅色背景，松绿色重点按钮，图表与日历使用低饱和配色；无外部字体或图片请求。表单有可见标签，支持键盘和原生 dialog。

独立数据层使用 Node 内置测试验证数量折算、模板快照、日期、导入校验与趋势。浏览器验证新增/多选/编辑/删除、刷新、日历跨日、备份恢复和手机宽度。GitHub Pages 发布后验证远程 SHA、构建状态和访问。
